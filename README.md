# admin-dashboard
A project to create a dashboard using flex box and css grid.
age → grid, 2 columns (sidebar | right side)
Sidebar → flex column (heading, two nav lists)
Right side → header on top, main content below
Header → flex column of two rows; each row is a flex row with space-between; the greeting is a nested row (avatar + text-block-as-column)
Main content → projects area beside the side panel
Your Projects → heading + responsive card grid (auto-fill + minmax)
Side panel → flex column of two units; each unit = heading + panel
